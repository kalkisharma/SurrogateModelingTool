► What is a surrogate model? — click to learn before you start

A surrogate model is a fast mathematical approximation trained on a small set of CFD runs. Example: run 100 RANS simulations across your angle-of-attack and Mach number envelope, upload the results here, and the surrogate predicts CL and CD for 10,000 new design points in seconds — without queuing another solver job.

Works for any tabular simulation data: aerodynamic, structural, thermal, or propulsion. One row per simulation run, design parameters as input columns, outputs as separate columns.

Minimum data: 30+ simulation runs recommended. Gaussian Process Regression (GPR) works well from 30–500 rows. Random Forest from 100–2,000 rows.

⚠ Outlier Detection —

How it detects outliers: We measure the typical spread of each column using the interquartile range (IQR) — the gap between the 25th and 75th percentile values. Any data point more than 1.5× that gap above or below the middle is flagged.

Why it matters for your surrogate: A single anomalous CFD run — a diverged solution or transcription error — can pull the fitted model away from your real operating envelope, reducing accuracy across the entire design space.

When to exclude: Exclude if the flagged row represents a numerical error or physically impossible condition. Keep it if it is a real edge-case design point — but expect lower surrogate accuracy in that region.

Divides your data into k groups. The model is trained and tested k times, each time using a different group as the test set. The CV score is the average across all k tests — a more reliable accuracy estimate than a single split, at the cost of k× longer training time.

Recommended when you have fewer than 50 simulation runs. For 96+ runs a single 80/20 split is usually sufficient.
